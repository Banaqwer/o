# Reaction statistics on real futures bars

Run on 9 November 2026. Data: London Strategic Edge `/vault/candles`,
1-minute continuous front-month candles with volume, `NASDAQ100.F` and
`GOLD.F`, 2025-11-02 to 2026-11-08 (358,320 and 351,291 bars). Daily
context from FRED (VIX, 10y-2y) and the French library. Engine defaults,
no parameter tuned to this data. Reaction is measured in sigma units of the
dispersion `rho` at the time of each level test: MFE is the maximum move in
the rung's direction within the horizon, MAE the maximum move against it,
edge = MFE - MAE. "Reverted" is the share of events after which price
revisited the session anchor within the horizon.

Gold's reaction is short-lived: entries react for 5-15 bars and the edge
is gone by 60 bars. Buying rungs lost money over the hour in this sample
while selling rungs worked, which is a directional-drift signature rather
than two-sided reversion. The split-sample check is flat (first half +0.12
at h=15, second half -0.04).

## How to read this

* These are excursion statistics, not P&L. MFE - MAE is not a return a
  trader could have captured; no entry rule, exit rule, cost or slippage is
  modelled, by design (the source states the engine carries no execution
  logic).
* Events overlap in time and within sessions, so the t-statistics overstate
  independence. The split-sample and the monotone score quartiles are the
  more trustworthy evidence.
* One year of one continuous series per instrument, from a single vendor.
* The thresholds that define an entry are rolling quantiles computed from
  past events only; nothing in the run uses future bars.

Regenerate with:

```bash
export LSE_API_KEY=...   # a Terminal/Databank key answers on /vault
atm-engine fetch-lse --api vault --symbol NQ --timeframe 1m --start 2025-11-01 --end 2026-11-09 --out nq_1m.csv
atm-engine fetch-lse --api vault --symbol GC --timeframe 1m --start 2025-11-01 --end 2026-11-09 --out gc_1m.csv
atm-engine context --start 2015-01-01 --out context.csv
atm-engine replay nq_1m.csv --instrument NQ --context context.csv
atm-engine replay gc_1m.csv --instrument GC --context context.csv
```
